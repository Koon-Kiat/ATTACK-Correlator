## Reproducibility and limits

normalization-manifest.json records source/code/configuration/output/report hashes. The offline elastic-mapping.json contract uses date_nanos and disables parsing of original payloads, preventing arbitrary source columns from expanding mappings. Every output was checked against that local contract; actual Elasticsearch acceptance remains Phase 4 work. Use ordinary indices for unresolved timestamps; do not let Logstash substitute its current time.

Original fields omit only exact empty CSV cells; source-schemas.json records every header in order so restore_row can reconstruct every original parsed row. Publisher metadata is retained in publisher-metadata.json; full per-row source mapping values remain under windows_apt.scenario.source_mapping.
