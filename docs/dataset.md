# Dataset preparation and evidence

Required source: [Windows-APT 2025, Mendeley Version 4](https://data.mendeley.com/datasets/b8fmtzvpy8/4),
DOI `10.17632/b8fmtzvpy8.4`, CC BY 4.0. Download through that version-specific page;
record the download date and source URL. Do not recreate the publisher's attacks.

The supplied ZIP was prepared using `scripts/prepare_dataset.py`; its local
preparation report records the archive hash and every extracted file's hash.
The current **v4** package contains 28 files, including 20 CSVs: 16 period exports,
`combined.csv`, `scenario_manifest.csv`, `validation_summary.csv` and
`scenario_mapping_supplement/log_to_scenario_mapping.csv`. It also contains publisher
documentation, checksums, processing scripts and a supplement notebook. These are
observed archive entries, not an inferred schema.

The bundled README describes `combined.csv` as a merged convenience copy of the period
logs. The updated README explicitly documents the v4 supplement, while its citation
still references the base v3 DOI. The user supplied the replacement as v4, and its
contents include the v4 mapping supplement. Cite the requested version-specific v4
record and retain the original publisher citation. All **20** supplied CSV checksum
entries, including the mapping supplement, matched the extracted bytes.

Preparation-time archive SHA-256 (the root ZIP is no longer present at dataset inspection review):
`d427e5c58ca22fe36aadc4f0ccc365b061c33dbee7dd020cc492d3d1c4a10708`.
This is a local provenance fingerprint, not independent publisher authentication.

Never add counts across combined and period files without checking overlap. Never
assume scenario-level validation amounts to benign/malicious event-level ground truth.
The v4 README describes scenario assignments as **derived soft labels**, computed using
technique matching and episode context. Treat them as contextual attribution rather
than independent truth for evaluating technique rules. dataset inspection verified the actual
join keys, ambiguity and attribution-strength fields.

## Current read-only inspection

The complete scan of the replacement v4 extract inspected all 20 CSVs without
structural parsing failures. It found 102,011 records and 377 columns in `combined.csv`,
102,011 records and 13 columns in the scenario-mapping CSV, and 36 records each in the
manifest (8 columns) and validation summary (9 columns). These are per-file row
counts, not independent event totals, detections or accuracy measurements.

The manifest and validation files actually spell their key `Scenrario_ID`, while the
supplement contains `Scenario_ID`, `Source_CSV` and `Row_Index`. The manifest also
contains `Simiulated Tactics`. Preserve these source spellings; do not silently
correct them in raw evidence. The mapping joins period files using `Source_CSV` and
zero-based `Row_Index`, then links its `Scenario_ID` to manifest `Scenrario_ID`.
The supplement's README example using `combined.csv` does not match the actual mapping.
